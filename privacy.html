最後更新：2026-11-12

「水豚快報（Capy Brief）」使用一個自用的上傳工具，透過 Google 的 YouTube Data API，把我們自己製作的影片發布到自己的 YouTube 頻道 @capybrieftw。

我們存取哪些資料

  • 工具只在頻道擁有者本人授權後，存取該頻道的資料，用途僅限於：上傳影片、設定縮圖與字幕、修改影片標題與說明、查詢影片處理狀態、刪除自己的影片。
  • 不讀取、不收集任何觀眾或其他使用者的個人資料。

資料如何保存

  • Google 發給的授權憑證只保存在頻道擁有者自己的電腦上，不上傳到任何伺服器，也不提供給第三方。
  • 擁有者可以隨時到 Google 帳戶的第三方存取權限撤銷授權。

本工具對 Google API 資料的使用遵守 Google API Services User Data Policy，包括有限使用（Limited Use）規定；也遵守 YouTube 服務條款與 Google 隱私權政策。
